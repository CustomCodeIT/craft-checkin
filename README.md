# CheckIn Plugin for Craft CMS

> [!WARNING]  
> Despite this being a 1.x release, this plugin is still in active development and could change (or break) at any time.  
> I am developing this to meet my own needs but am happy to take feedback/ideas if I can help make it work for you.

## About
The CheckIn plugin has been developed to provide some simple endpoints to extract useful information about your Craft instances.  
There is a companion client coming shortly that will give you the ability to add your sites (that have the plugin installed) to a dashboard.  
This client will be free and self-hosted. I have no interest in turning this into a paid solution. 

So far, this is a very simple plugin with not much happening. We're basically adapting the native update controller in Craft to provide JSON output about updates.  
More features will be coming but this was the highest priority on the list 

## Usage Examples
A good example (and the reason I built this) is if you're an agency that manages many Craft websites, and you need to see information about all your sites in one place.
